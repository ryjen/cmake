# Historical CMake helpers

> [!NOTE]
> **Seamwork transition — ARCHIVE candidate.** This repository contains historical CMake helpers used by the former `libcoda` aggregate and its component repositories. Active [Seamwork](https://github.com/ryjen/seamwork) no longer depends on this repository or its submodule layout.

The code remains available for provenance and reproduction of historical builds. New Seamwork work should keep build logic local to the active repository or use current organization-wide tooling rather than depending on these helpers.

The legacy repositories that still reference this repository are themselves historical/archival inputs.
